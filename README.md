# Nauralta status page (development)

The development-environment counterpart of nauralta/statuspage. This repository holds
nothing by hand — `index.html` is overwritten automatically by the Nauralta Portal
worker (`Nauralta.Portal.Worker.StatusPage.GitHubPagesPublisher`) whenever something the
status page shows changes. Do not edit it directly; changes will be overwritten on the
next publish.

Served via GitHub Pages, from the `main` branch, root folder, on dev.status.nauralta.com.
